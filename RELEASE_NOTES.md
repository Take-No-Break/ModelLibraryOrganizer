# v1.0.0

First public 1.0.0 release of Model Library Organizer, following development previews.

- Model inspection with available public trigger words, descriptions and preview images.
- SHA-256 source identification and reviewed organization with linked recovery journals.
- Readable model source TXT, family-based LoRA/checkpoint comparison and duplicate reports.
- Local ComfyUI Image to Text workflows, direct node setup and hardlink/TXT output folders.
- Individual/bulk caption editing and visual Tag editor.
- Illustrated README with linked feature table and numbered instructions.
- Complete button/control reference for users and AI assistants.

Weights and ComfyUI are separate. Metadata compatibility estimates are not generation tests. Scan inventories need linked move journals to restore. Uninstaller included but not executed/tested; no VM/second-PC test claimed.

Development preview v1.0.32 remains available as an earlier prerelease. The public release version is intentionally reset to 1.0.0; its core functionality comes from that preview.
